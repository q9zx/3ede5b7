# METRI.IMMO LINK FRAMEWORK — FX9

Micrositio estático del local comercial en alquiler en el Casco de Chacao.

## Archivos

- `index.html`: contenido, metadatos SEO, mapa y datos estructurados.
- `styles.css`: identidad visual y adaptación responsive.
- `script.js`: galería y lightbox accesible.
- `favicon.png`: favicon del inmueble.

## Actualizaciones

- Para sustituir fotografías, cambie las URL del arreglo `propertyImages` en `script.js` y la imagen principal, Open Graph y JSON-LD en `index.html`.
- Para modificar SEO, actualice `title`, description, canonical, Open Graph, Twitter y JSON-LD en `index.html`.
- Para actualizar el mapa, reemplace únicamente el atributo `src` del iframe de la sección `#mapa`.
- Para publicar, copie el contenido de esta carpeta en `/FX9/` del repositorio y active GitHub Pages para la rama correspondiente.

No requiere instalación, dependencias ni compilación. Puede abrirse directamente mediante `index.html`.
